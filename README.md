# Complaint Management System

A professional web-based **Complaint Management System** that allows users to submit complaints, receive a unique complaint ID, and track the status of their complaints online.

## 📌 Features

* 📝 Submit complaints online
* 👤 Collect user information
* 📂 Select complaint category
* 🆔 Generate a unique complaint ID
* 🔍 Track complaints using complaint ID
* 📊 Display complaint status
* ⚡ Fast and user-friendly interface
* 📱 Responsive design for different screen sizes
* 🔐 Basic server-side validation

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone YOUR-GITHUB-REPOSITORY-URL
```

### 2. Open the project folder

```bash
cd "Complaint Management System"
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
npm start
```

### 5. Open in browser

```text
http://localhost:3000
```

## 📋 Complaint Categories

The system supports different complaint categories such as:

* Service Issue
* Product Issue
* Payment Issue
* Technical Issue
* Staff Complaint
* Other

## 📊 Complaint Status

A complaint can have different statuses, such as:

* **Pending**
* **Processing**
* **Resolved**

## 🎯 Project Objective

The main objective of this project is to provide a simple digital platform for registering and tracking complaints. It reduces manual complaint handling and makes the complaint process more organized and transparent.
